## Honeycomb Menu NG v1.4.4 – Sonos Artwork-Only Favorites

This pre-release makes one isolated Sonos favorites visual change.

### Radio favorites
- Favorites with cached artwork/logo now show the artwork only.
- The fallback radio icon is hidden when artwork exists.
- The favorite name/text is also hidden when artwork exists.
- Favorites without artwork keep the existing radio icon + text fallback.

### Scope
No Light, core navigation, anchor, ring geometry or Sonos control behavior is changed.
